# Faces used for rendered images

`image` outlines these faces, so a machine that does not have them installed still matches.

- Inter Regular and Inter Medium (SIL Open Font License). Body copy and keys. These are the brand's text faces.
- TeX Gyre Heros Regular (GUST Font License). Headings and the wordmark. The brand's display face is Neue Haas Grotesk Display at weight 500, which cannot be redistributed. Where it is not installed the brand uses Helvetica, and Heros is a Helvetica-compatible cut. Heros has no medium master, so images use the regular cut.
- JetBrains Mono Regular (SIL Open Font License). Labels, window bars and code, in the role of the platform monospace.

The license texts sit beside the files. The font files are unmodified.
